# 가볍지이지 디자인 시스템

가볍지이지(LightEZ) 브랜드 전반, SignalB 웹 앱·대시보드, 고객용 캠페인 리포트가
같은 토큰을 쓰도록 만든 레퍼런스다. **`index.html` 한 파일이 전부**이고, 이 저장소가
소스 오브 트루스다.

- 열기: `open index.html` (빌드 없음, 외부 요청은 서체뿐)
- 참고: 토스 TDS(타이포·해요체 라이팅), 당근 SEED(2단 토큰·4px 치수·라운드·모션)
- 결: 당근처럼 둥글고 따뜻하게, 색은 가볍지이지 민트

## 정해진 것

| 항목 | 값 |
|---|---|
| 메인 컬러 | `#2ed8c3` (mint-400) — 흰 바탕 버튼은 mint-600 `#0fa08d`, 글자·링크는 mint-700 `#0b7f70` |
| 헤딩 서체 | 에이투지체 (눈누 1778, OFL) — jsdelivr, 500/600/700 |
| 본문 서체 | Apple SD Gothic Neo — 시스템 서체. 비-Mac은 Pretendard → 맑은 고딕 폴백 |
| 대화체 서체 | 그리운X국한박 뚜레 (눈누 1889, OFL) — 캐릭터 대사·인사 한 줄에만 |
| 토큰 구조 | 스케일 `--c-mint-400` → 시맨틱 `--bg-brand` / `--fg-primary` / `--stroke-default` |
| 테마 | 라이트(bare `:root`) → OS 다크(`:root:not([data-theme="light"])`) → 토글 다크(`[data-theme="dark"]`) → 인쇄는 라이트 강제 |
| SignalB 등급 | 강력 추천·추천 → ok, 관찰 → warn, 주의·회피 → danger. `--bg-brand`는 등급에 쓰지 않는다 |
| 데이터 없음 | 0 / 데이터 없음 / 미확인은 다른 상태 — 막대를 그리지 않는다 |

## 페이지 구성

원칙 → 브랜드 → 컬러(램프·시맨틱·등급 매핑·대비 실측) → 타이포(+대화체) →
간격·형태·모션 → 컴포넌트·앱 → 컴포넌트·리포트 → 라이팅 → 다크모드·인쇄 →
토큰 전체 목록(필터·복사) → 마이그레이션(SignalB 기존 변수 → 새 토큰)

## 고칠 때

- 토큰은 CSS `:root` 블록과 `<script>`의 `RAMPS` / `SEMANTIC` / `OTHER` 두 군데에 있다.
  둘이 어긋나면 페이지가 콘솔에 `[토큰 드리프트]` 경고를 띄운다 — 둘 다 고친다.
- 다크 값은 ②(OS 다크)와 ③(토글 다크) 블록에 같은 값으로 두 번 있다. 같이 고친다.
- 컴포넌트는 시맨틱 토큰만 본다. 미디어쿼리 안에 컴포넌트 규칙을 쓰지 않는다.

## 마크 (assets/)

원본 래스터 `assets/source/mark-original-1254.png`를 잎 3장으로 분리(열 스캔)한 뒤,
외곽선을 **3차 베지어로 다시 맞췄다**(Schneider 피팅, 코너에서 분할). 잎당 12·11·15 세그먼트.
그라데이션은 잎마다 **색이 실제로 변하는 축을 회귀로 찾아** 원본에서 5스톱을 샘플했다.

| | 실루엣 IoU | 색차 | 세그먼트 | mark.svg |
|---|---|---|---|---|
| 자동 트레이스(v2, 2026-09-12 초판) | 0.9704 | 13.6 | 143 | 6.1KB |
| **베지어 재구성(현재)** | **0.9747** | **11.5** | **38** | **2.6KB** |

시도했다가 버린 것: 원본에는 잎 가운데를 지나는 밝은 띠가 있는데, 흰색 오버레이를
선형 그라데이션으로 얹어봤더니 색차가 11.5 → 14.3 으로 **나빠졌다**. 그 띠는 잎의 굽은
등줄기를 따라가는 곡선이라 직선 그라데이션으로는 표현할 수 없다(수직 좌표 2차 적합 R² 0.00~0.05).
살리려면 곡선 오버레이 path + 블러 필터가 필요하고, 그건 인쇄·임포트에서 깨질 수 있어 택하지 않았다.

| 파일 | 쓰임 |
|---|---|
| `mark.svg` | 기본. 흰·밝은 바탕 |
| `mark-dark.svg` | 어두운 바탕 — 그라데이션을 한 단계 밝게 |
| `mark-tone.svg` | 3톤 단색(민트 300/500/700) — 그라데이션이 안 되는 곳 |
| `mark-onbrand.svg` | 민트 바탕 위 — 짙은 3톤 |
| `mark-flat.svg` | 완전 단색 `currentColor` — 인쇄·워터마크 |
| `mark-small.svg` | **32px 이하 전용.** 잎을 28px 깎고 원래 bbox로 다시 키워 틈을 넓혔다 |
| `favicon/mark-{16,24,32}.png` | 소형 마크에서 생성 |
| `favicon/mark-{48…512}.png` | 기본 마크에서 생성 |

viewBox는 다섯 파일 모두 `52 81 1056 1056`(정사각, 마크 가운데 정렬)라 서로 바꿔 끼울 수 있다.
잎은 `#leaf-top` `#leaf-mid` `#leaf-bot` 세 path이고 그리는 순서가 곧 z-order(아래 잎이 맨 위)다.

Figma 브랜드 파일: https://www.figma.com/design/25DpM8yBlpfhiZnQ8k8nWK (가볍지이지 브랜드, Test Design 팀).
비어 있다 — `assets/*.svg` 를 캔버스에 끌어다 놓으면 그라데이션까지 그대로 들어온다.
MCP 로 자동 배치하려면 Figma Starter 플랜의 월 20회 도구 호출 한도를 넘겨야 한다.

## 아직 없는 것


- 공유용 `tokens.css`. 지금은 문서 안에만 있다. 필요해지면 `:root` 블록을 그대로 떼어 낸다.
- SignalB 실제 화면 적용. `#migration` 표가 대응표이고 교체는 SignalB 저장소에서 한다.

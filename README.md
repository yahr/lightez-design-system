# 가볍지이지 디자인 시스템

가볍지이지(LightEZ) 브랜드 전반, SignalB 웹 앱·대시보드, 고객용 캠페인 리포트가
같은 토큰을 쓰도록 만든 레퍼런스다. **`index.html` 한 파일이 전부**이고, 이 저장소가
소스 오브 트루스다.

- 열기: `open index.html` (빌드 없음, 외부 요청은 서체뿐)
- 참고: 토스 TDS(타이포·해요체 라이팅), 당근 SEED(2단 토큰·4px 치수·라운드·모션)
- 결: 당근처럼 둥글고 따뜻하게, 색은 가볍지이지 민트

## 정해진 것

| 항목 | 값 |
|---|---|
| 메인 컬러 | `#2ed8c3` (mint-400) — 흰 바탕 버튼은 mint-600 `#0fa08d`, 글자·링크는 mint-700 `#0b7f70` |
| 헤딩 서체 | 에이투지체 (눈누 1778, OFL) — jsdelivr, 500/600/700 |
| 본문 서체 | Apple SD Gothic Neo — 시스템 서체. 비-Mac은 Pretendard → 맑은 고딕 폴백 |
| 대화체 서체 | 그리운X국한박 뚜레 (눈누 1889, OFL) — 캐릭터 대사·인사 한 줄에만 |
| 토큰 구조 | 스케일 `--c-mint-400` → 시맨틱 `--bg-brand` / `--fg-primary` / `--stroke-default` |
| 테마 | 라이트(bare `:root`) → OS 다크(`:root:not([data-theme="light"])`) → 토글 다크(`[data-theme="dark"]`) → 인쇄는 라이트 강제 |
| SignalB 등급 | 강력 추천·추천 → ok, 관찰 → warn, 주의·회피 → danger. `--bg-brand`는 등급에 쓰지 않는다 |
| 데이터 없음 | 0 / 데이터 없음 / 미확인은 다른 상태 — 막대를 그리지 않는다 |

## 페이지 구성

원칙 → 브랜드 → 컬러(램프·시맨틱·등급 매핑·대비 실측) → 타이포(+대화체) →
간격·형태·모션 → 컴포넌트·앱 → 컴포넌트·리포트 → 라이팅 → 다크모드·인쇄 →
토큰 전체 목록(필터·복사) → 마이그레이션(SignalB 기존 변수 → 새 토큰)

## 고칠 때

- 토큰은 CSS `:root` 블록과 `<script>`의 `RAMPS` / `SEMANTIC` / `OTHER` 두 군데에 있다.
  둘이 어긋나면 페이지가 콘솔에 `[토큰 드리프트]` 경고를 띄운다 — 둘 다 고친다.
- 다크 값은 ②(OS 다크)와 ③(토글 다크) 블록에 같은 값으로 두 번 있다. 같이 고친다.
- 컴포넌트는 시맨틱 토큰만 본다. 미디어쿼리 안에 컴포넌트 규칙을 쓰지 않는다.

## 마크 (assets/)

마크는 **바깥 윤곽이 하나의 곡선**이다. 줄기 끝에서 맨 위 깃털 끝까지 끊기지 않고 이어지고,
세 깃털은 안쪽에서 파인 노치로만 갈라진다. 전체가 `<path>` 한 장(3차 베지어 26 세그먼트)이고,
색은 위에서 아래로 흐르는 세로 그라데이션 하나다 — `#5fe2cf → #2ed8c3 → #0fa08d`.

만든 방법: 원본 래스터(`assets/source/mark-original-1254.png`)에서 세 깃털을 분리해 합집합을 구하고,
그 합집합의 윤곽을 한 번에 베지어로 맞췄다(코너는 줄기 끝·깃털 끝 3개·노치 바닥 2개, 정확히 6개).

| 파일 | 쓰임 | 크기 |
|---|---|---|
| `mark.svg` | 기본. 흰·밝은 바탕 | 1.4KB |
| `mark-dark.svg` | 어두운 바탕 — 그라데이션을 한 단계 올림 | 1.4KB |
| `mark-onbrand.svg` | 민트 바탕 위 — 짙게 내림 | 1.4KB |
| `mark-flat.svg` | 단색 `currentColor` — 인쇄·워터마크 | 1.1KB |
| `mark-small.svg` | **32px 이하 전용.** 노치를 18px 넓혀 작은 크기에서 깃털이 안 뭉개진다. 큰 크기에 쓰지 않는다 | 1.4KB |
| `favicon/mark-{16,24,32}.png` | 소형 마크에서 생성 | |
| `favicon/mark-{48…512}.png` | 기본 마크에서 생성 | |

viewBox 는 모두 `52 81 1056 1056` 라 서로 바꿔 끼울 수 있다.
그라데이션 id 는 파일마다 다르다(`lez-mark`, `lez-mark-dark`, …) — 한 페이지에 여러 개를 인라인해도
id 가 충돌하지 않게 하기 위해서다. **새 변형을 만들 때도 id 를 반드시 바꾼다.**

원본 추적을 그만둔 이유: 원본 PNG 는 투명 체커보드가 배경에 구워진 캡처본이라 깨끗한 마스터가 아니다.
잎 가운데를 지나는 광택 띠를 선형·타원 그라데이션으로 두 번 재현해봤지만 둘 다 색차가 나빠졌다
(11.5 → 14.3, → 11.8). 래스터를 좇는 대신 단색 + 하나의 윤곽으로 다시 정리했다.

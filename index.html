가볍지이지 디자인 시스템

가볍지이지 브랜드 전반, SignalB 웹 앱과 대시보드, 그리고 고객이 받는 캠페인 리포트가 같은 토큰을 쓰도록 만든 레퍼런스예요. 당근 SEED의 토큰 구조와 형태, 토스의 타이포·라이팅 규칙을 참고하되 색과 서체는 우리 것으로 골랐어요.

가볍지이지 디자인 시스템 v0.1 · 2026-09-12 메인 컬러 #2ed8c3 헤딩 에이투지체 · 본문 Apple SD Gothic Neo · 대화체 뚜레 외부 요청: 서체만

원칙

결정을 앞두고 헷갈릴 때 돌아오는 네 문장이에요. 컴포넌트 규칙은 전부 여기서 나와요.

가볍게

한 화면에 색은 민트 하나, 강조는 한 군데. 밀도를 낮춰 숫자와 글이 먼저 읽히게 해요.

정직하게

없는 데이터는 없다고 써요. 0과 '데이터 없음', '미확인'은 다른 상태라 다르게 그려요.

따뜻하게

둥근 모서리, 해요체, 친근한 어휘. 소상공인 셀러가 부담 없이 읽는 톤이에요.

인쇄돼도 읽히게

리포트는 PDF가 돼요. 다크모드에서도, 흑백 프린터에서도 위계가 남아야 해요.

브랜드

마크는 민트 깃털이에요. 바깥 윤곽이 하나의 곡선이에요 — 줄기 끝에서 맨 위 깃털 끝까지 끊기지 않고 이어지고, 세 깃털은 안쪽에서 파인 노치로만 갈라져요. 전체가 path 한 장(세그먼트 26개)이고 위에서 아래로 흐르는 세로 그라데이션 하나를 써요. 파일은 mark.svg(기본) · mark-dark.svg(어두운 바탕) · mark-onbrand.svg(민트 바탕) · mark-flat.svg(단색 currentColor) · mark-small.svg(32px 이하)예요.

가볍지이지민트 바탕 · 단색 마크
사용 규칙
이렇게
  • 워드마크는 헤딩 서체(에이투지체 700)로, 마크 높이의 1/2 여백을 사방에 둬요
  • SignalB 제품명은 "SignalB" 한 단어로 붙여 써요. 리포트 kicker에서만 "Signal B · 시장 신호 리포트"를 허용해요
  • 32px 이하에서는 mark-small.svg를 써요 — 노치를 18px 넓힌 판이라 작은 크기에서 깃털이 안 뭉개져요. 큰 크기에는 쓰지 않아요
  • 마크 최소 크기 16px(파비콘), 워드마크 최소 12px
이렇게는 안 돼요
  • 마크에 그림자·외곽선을 얹지 않아요. 그라데이션은 파일에 든 세로 하나만 써요
  • 민트 위에 민트 마크를 두지 않아요 — 민트 바탕에는 단색(짙은 민트) 마크
  • 바깥 윤곽을 끊거나 깃털을 따로 떼어 쓰지 않아요 — 하나의 선이 이 마크의 정체성이에요

컬러

두 층이에요. 스케일(--c-mint-400 같은 원색)은 테마와 상관없고, 시맨틱(--bg-brand, --fg-primary)이 라이트/다크에서 값을 바꿔요. 컴포넌트는 시맨틱만 써요.

스케일

메인 컬러 #2ed8c3은 민트 400이에요. 흰 바탕에서 글자로는 대비가 안 나와서(1.9:1) 큰 면·아이콘·다크모드 포인트에만 쓰고, 흰 바탕의 버튼은 600, 링크·글자는 700을 써요.

시맨틱

당근 SEED처럼 bg / fg / stroke 로 나눴어요. 상태색은 -soft(바탕) 위에 -ink(글자), 테두리는 -line이에요.

토큰미리보기라이트다크쓰임

SignalB 등급 매핑

등급은 색이 아니라 역할이에요. 강력 추천과 회피는 채운 배지, 나머지는 연한 배지라 같은 색이어도 강도로 구분돼요. --bg-brand는 등급에 쓰지 않아요 — 구조·액션 전용이에요.

대비 실측

지금 보고 있는 테마의 실제 값으로 계산해요. 테마를 바꾸면 표도 바뀌어요. 본문 글자는 4.5:1, 채움 버튼의 굵은 글자와 큰 숫자는 3:1이 기준이에요.

타이포

세 서체예요. 헤딩은 에이투지체(눈누 1778, OFL — 상업 사용 가능), 본문은 Apple SD Gothic Neo, 그리고 캐릭터가 말하는 자리엔 손글씨 그리운X국한박 뚜레(눈누 1889, OFL)예요. 본문 서체는 시스템 폰트라 Mac에서만 그대로 보이고, Windows나 고객 PDF 뷰어에서는 Pretendard → 맑은 고딕 순으로 떨어져요. 이건 의도된 폴백이라 깨진 게 아니에요.

대화체 · 뚜레

친근하게 말을 거는 자리 — 캐릭터 소개, 온보딩 인사, 빈 화면의 한 줄 — 에만 써요. 손글씨라 본문보다 한 단계 크게(18px), 줄간격은 1.7이에요. 데이터·버튼·리포트 본문엔 쓰지 않아요.

짹

안녕, 나는 이지짹이야. 가볍지이지에서 제일 먼저 신호를 알아채는 새지. 오늘은 양말부터 볼까?

짹

리뷰 1,240건 다 읽었어. 두께 얘기가 제일 많더라.

사용 규칙
이렇게
  • 말풍선 안, 캐릭터 이름 옆 — 누가 말하는지 보이는 자리
  • 한 번에 두 문장 이내. 숫자는 여기서도 아라비아 숫자
  • 주변은 본문 서체로 — 손글씨는 한 화면에 한 덩어리
이렇게는 안 돼요
  • 헤딩·버튼·라벨·표에 쓰지 않아요
  • 리포트의 근거·수치·등급 근처엔 두지 않아요 — 신뢰가 흔들려요
  • 12px 아래로 줄이지 않아요 — 삐뚤한 획이 뭉개져요

다크모드 · 인쇄

보는 사람의 상태는 셋이에요 — 시스템(아무 표시 없음), 명시적 라이트, 명시적 다크. CSS는 세 블록으로 이걸 다 받아요. 인쇄는 항상 라이트예요.

CSS 구조
/* ① 라이트 전체 — 모든 토큰이 여기 먼저 선언돼요 */
:root { --bg-page: #f7f9fb; --fg-primary: #16202b; … }

/* ② OS 다크. 명시적 라이트가 아니면 */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --bg-page: #10161d; … }
}

/* ③ 토글로 고른 다크. ②와 같은 값 — 둘을 같이 고쳐요 */
:root[data-theme="dark"] { --bg-page: #10161d; … }

/* ④ 인쇄 — 라이트 강제, 그림자 제거, 잘림 방지 */
@media print {
  :root { --bg-page: #fff; --sh-1: none; … }
  .card, .entity, tr { break-inside: avoid; }
  h2, h3 { break-after: avoid; }
  .axis-bar-fill, .badge { print-color-adjust: exact; }
}
이렇게
  • 컴포넌트는 시맨틱 토큰만 봐요. 미디어쿼리 안에 컴포넌트 규칙을 쓰지 않아요
  • 다크에서 브랜드는 민트 400(#2ed8c3)으로 올리고, 그 위 글자는 짙은 민트
  • 다크 그림자는 1px 링 + 짙은 그림자
이렇게는 안 돼요
  • 색을 [data-theme] 블록 안에서만 정의하지 않아요 — 시스템 상태에서 안 보여요
  • 라이트 값을 단순 반전하지 않아요 — 앰버·그린은 따로 골라요

토큰 전체 목록

페이지의 실제 CSS 변수에서 읽어 와요. 라이트/다크 값이 문서와 다르면 콘솔에 경고가 떠요. 이름을 누르면 var(--이름)이 복사돼요.
